
# Minesweeper

A simple browser-based Minesweeper game built with HTML, CSS, and JavaScript.

## Features

- 9×9 grid with 10 mines
- Safe first move
- Automatic reveal of empty areas
- Flagging and mine counter
- Timer and restart button
- Win and loss detection
- Responsive interface

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start playing.

No dependencies or build tools are required.

## Controls

- Left-click a cell to reveal it.
- Right-click a cell to flag or unflag it.
- On mobile, use Flag mode to mark cells.
- Click the face button to restart.

## Technologies

- HTML5
- CSS3
- JavaScript
